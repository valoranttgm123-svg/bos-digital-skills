## Checks

- [ ] Header names are unique and meaningful.
- [ ] Required fields are not unexpectedly blank.
- [ ] Key values have valid and consistent types.
- [ ] Duplicate keys are investigated.
- [ ] Dates and currencies use consistent formats.
- [ ] Negative, zero, or unusually large values are explained.
- [ ] Joins between sheets do not drop or multiply rows unexpectedly.
- [ ] Totals reconcile to the source.
- [ ] Filters and exclusions are documented.
- [ ] Source data remains unchanged.
