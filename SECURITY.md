# Security Policy

## Supported release

Security reports are welcome for the current default branch and the latest tagged release.

## Reporting

Do not publish credentials, tokens, personal data, or a working exploit in a public issue. Use GitHub's private vulnerability reporting feature for this repository when available, or contact the repository owner through a private channel listed on the GitHub profile.

Include the affected skill/path, impact, reproducible steps, and a proposed mitigation where safe.

## Scope

This repository primarily contains agent instructions and examples. Report unsafe instructions, secret exposure, malicious links, untrusted downloads, dangerous automation defaults, or privacy risks.

Do not test against systems you do not own or have permission to assess.
